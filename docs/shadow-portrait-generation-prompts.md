## Common Style (모든 prompt prefix)
```
dark fantasy shadow soldier portrait, transparent background, centered full body silhouette, black and deep violet shadow smoke body, mobile RPG card art, game UI ready, no text no frame no background scene
```

## Common Negative Prompt
```
no background scene, no text, no logo, no frame, no human skin tone, no bright cartoon style, no realistic gore, no cluttered environment, no cropped body, no duplicate characters, no weapon blocking silhouette completely, no white or gradient background
```

**Output:** WebP 512×768. Folder: `/public/assets/shadows/<assetFamily>/<portraitKey>.webp`

> Illustrator reference for unique assetFamily silhouette rules.

- **`rat`** (shadow-rat): fully four-legged, tail 60%+ body height, no humanoid posture
- **`spearman`** (shadow-spearman): diagonal spear must span full frame corner-to-corner
- **`executor`** (dark-executor): shoulder width 1.5× standard, sword points DOWN, horn helmet prominent
- **`rift`** (rift-fang/trainee/gladiator/champion): body is NOT solid. Crack density increases with evolution tier. Colors: trainee=teal, fang=red, gladiator=red-violet, champion=crimson
